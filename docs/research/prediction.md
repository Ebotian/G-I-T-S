# 两类预测：外部给的 vs 自己学的

> 天气和"他会不会发消息"看起来都是"预测"，但它们的**证据来源**不同，
> 所以纪律也不同。混在一起写，早晚会把一个说成另一个。

## 1. 分界线不是实现，是证据从哪来

| | 外部预测 | 自建预测 |
|---|---|---|
| 例子 | 明天有雨 | 他这会儿在家的概率 |
| 谁给的 | 有人替我们看过（高德） | 我们自己从轨迹和消息里估的 |
| 会不会错 | 会，但可以核对 | 永远带不确定性 |
| 能不能说成事实 | 能（"明天有雨"） | **不能**（只能说"大概"） |
| 代码 | world/forecast.py | world/coupling.py |

这两条线在数据上的分类也跟着不同：

    外部预测  -> 记录。有效期在将来，"明天有雨"明天之前一直成立。
                 所以进 C 段、只在窗口内出现，和生日走同一条通道（facts.due）。
    自建预测  -> 学出来的量。随时可以被新数据推翻，所以只进慢变量和 B 段，
                 而且只能以概率的形式出现。

## 2. 外部预测：说值得说的

四天预报天天都拿得到。每天说"明天多云"就是噪音——
**那不是信息，是广播。**

所以有两道筛子：

    窗口   今天、明天（lead_days=1）。两天以后的不说。
    值得说 有降水/风沙/雾霾，或者温差超过 12 度。其余不说。

并且和天气一样，**只说天气不说建议**：

    "明天白天小雨，4 到 9 度。"          <- 说
    "明天有雨，记得带伞。"                <- 不说。这是在替他想。

## 3. 自建预测：耦合不是加一个维度，是加一个先验

直译"时空耦合"是学 s(t, p)：24 个时段 x 7 天 x 8 个场所 = 1344 格。
每天 30 条消息、一个月 900 条 -> **0.67 条/格**。大部分格子永远是空的。

估出来的是噪声，而噪声的坏处不是"不准"，是**它会在错误的时刻很有把握地说话**。

所以用收缩（empirical Bayes）：

    全局 p0（该小时他在发消息的率）    <- 样本足够，当先验
    场所层 p(t|p)                      <- 以 p0 为先验的后验

    p = (k + m0 * p0) / (n + m0)          m0 = PRIOR_N = 20

数据少的格自动退化成全局；数据多的格才长出个性。闭式解，不需要 MCMC，
不需要 scipy。和 association=(w+a)/(w+a+b) 是同一个模式。

实测（合成数据，7 天，两个地方）：

    10 点     在家 0.095   在公司 0.142     <- 方向对，但被收缩拉近了
    一条观测  和全局的差 < 0.01             <- 没有资格有性格

**这就是为什么测试比的是倍数不是差值**：收缩本来就会把两个数拉近。

## 4. 场所是学出来的，名字不是

从坐标到"家"中间有两步，第二步不能自动做。

    聚类  网格 + 半径合并。半径跟精度走：30 m 的定位用 60 m。
    命名  **空**。第一次见只知道"有个地方我常去"。

从"20:00-08:00 有 90% 的时间在这个点"推断出"这是家"——那是猜。
猜错了她会在你上班时问"到家了？"。名字只能来自他说过的话。

没名字的时候，B 段退回城市级："他这会儿在温州市。"

## 5. 去抖：变化不一定是移动

同一个房间，WiFi 切流量，出口从家宽变运营商——轨迹上会"跳 40 公里再跳回来"。

    观测   每一条定位
    确认   连续 CONFIRM_N=2 次同向，且那个地方有证据广度

这和 slew 是同一种精神（不信任单次观测），但作用在**离散量**上，
所以手法是**迟滞**，不是限幅。

## 6. 什么算"一个地方"：两条都要

| 判据 | 挡的是什么 |
|---|---|
| 证据广度 n >= 3 | 一次性的点 |
| 停留 best_run >= 2 | **反复出现的单点跳转** |

第二条是被数据逼出来的：网络每切一次就是一个 40 公里的跳点，
一天十几次，攒一周就有 16 条——**光看次数，它比工作地点还像"地方"**。
但它的每一趟都只有一次读数，从来没有"停留"。

## 7. 还没做

- **会去哪**：coupling.next_place 现在只看相邻两跳，没有时间条件。
  真实的行为是"18 点从公司回家"，不是"从公司随机去某处"。
- **活动**：现在只有"在哪个场所"和"发不发消息"，没有"他在干什么"。
  这个需要和消息内容挂钩，等有内容了再说。
- **不确定性进决策**：现在这些率还没有接到 gate 上。
  接的时候要注意：**概率不是理由**。低概率不等于不该说话。
