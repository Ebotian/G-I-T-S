# 记忆的实验数据，以及一个否定结论

> 先说结论，因为它改变了接下来要做的事：
>
> **合成数据能验证实现对不对，但不能告诉我们哪条遗忘曲线是对的。**
> 这份生成器里没有「记忆强度」这个隐变量——未来的提及只取决于当前的簇状态。
> 所以三个候选模型打不出差异，而「只看最近一次」就已经接近上限。

## 1. 为什么第一版数据没用

最初的生成器只造消息：1019 条里 64 种文本、CV 1.24、单次出现 6.2%——**大致均匀**。
拿它测遗忘，A/B/C 会得一样的分：所有事实只出现一次，`touches` 恒为 0，
三个公式都退化成「按年龄衰减」。那不是「没通过」，是**没有区分力**。

于是有了 `synth/facts.py`：造**事实**，而不是文本碎片。

```
实体    Yule–Simon：新实体以恒定速率进入，旧实体按已有事实数吸引 → Zipf
提及    分簇：那阵子天天提（簇内几小时到两三天一次），
        然后销声匿迹，隔几周到几个月又说起一次（簇间）
查询    按当前热度采样，用**间接说法**提问（带实体名就测不出语义召回）
```

实测（90 天，seed=7）：

```
实体 32 · 事实 209 · 提及 398 · 查询 111
提及次数前 5: 46 / 12 / 11 / 11 / 11
只提过一次: 61%     CV = 1.68
被取代的旧版本: 9    查询分层: recent 88 / strong 30
```

生成器自己有 14 个测试盯着这些数（重尾、单次占比、间接提问、候选里不含过期版本……）。

## 2. 任务定义也改过一次

我最初写的是「30 天后问其中 30 件，看能不能选对」。那是错的：
**如果答案定义成「最近被提起的那条」，那「按最近排序」就 100% 正确**，
三个模型完全一样。

真正要检验的是遗忘本身——在没有任何新信号时，哪条该留在手边。
所以任务是**预测未来会不会被再提起**（这正是 FSRS 拟合的目标函数，
只不过它的标签是「复习时是否回忆成功」）。

指标：AUC + P@10，并按「活跃 / 沉寂」分层——只看总数会骗人，热门近期的总是赢。

## 3. 结果：差距在噪声里

180 天 × 5 个种子，预测未来 7 天是否被提起：

| 模型 | AUC | P@10 | AUC（沉寂层） |
|---|---|---|---|
| `touches`（次数） | 0.930±0.018 | 0.750±0.043 | 0.730±0.094 |
| `spacing`（间隔效应） | 0.929±0.019 | 0.752±0.057 | 0.684±0.113 |
| `actr`（base-level） | 0.898±0.021 | 0.646±0.065 | 0.635±0.038 |
| `recency`（基线） | 0.926±0.018 | 0.729±0.033 | 0.725±0.073 |
| `frequency`（基线） | 0.757±0.027 | 0.423±0.096 | 0.553±0.034 |

三件事：

1. **频率基线很弱**（0.757）——说明分层和指标是有区分力的；
2. **`touches` ≈ `spacing` ≈ `recency`**，差距 0.004 AUC，在种子间波动之内；
3. **`actr` 明显更差**——它不看「最后一次」，而在这份数据里那是最强的信号。

## 4. 为什么这不说明「间隔效应是错的」

我的生成器里，未来的提及概率只取决于**当前处于簇内还是簇间**。
它没有「记忆强度」这个状态：一次在快忘记时的召回，并不会让这条事实
将来更容易被想起——**因为我在生成时就没写这件事**。

所以让模型去找「间隔效应」，等于测它能不能发现数据里不存在的结构。
这不是实验失败，是实验设计上的一次明确否定：

> **能测实现，不能测理论。**

要检验「间隔效应是否成立」，需要真实数据：他到底会不会在某个时刻重新提起某件事，
以及那件事之前被提过几次、隔了多久。**这个标签只有真实的对话历史能给。**

## 5. 这对记忆层意味着什么

三条务实的结论：

1. **先用最简单的模型。** `touches` 就是 `S = S0·(1 + 0.3·ln(1+次数))`，一行。
   `spacing` 那套等有真实数据再换——反正换起来只是改一个函数。
2. **现在就要开始攒拟合所需的数据。** 不能等到想拟合的时候才发现没记。
   需要的是：每条记忆的每次「被真正用到」的时刻，以及之后**有没有**被再提起。
   我们有 `events` 和 `outcomes`，够用——但要在写入时就标出来。
3. **这个评测留在仓库里当回归测试。** 它证明不了理论，但能证明
   「有人把 r(t) 改坏了」——AUC 会掉到 0.5 附近。

## 6. 还没做的

- `synth` 的 `queries` 目前只用于将来检验检索（顺带产出了 111 条带真值的查询）
- 参数拟合：等 500+ 次真实接触，只上 3–5 个参数（数据量撑不起 19 个）
- 把 `events` 里「她用了哪条记忆」真正接上（`influence` 表已经有了，还没写）
