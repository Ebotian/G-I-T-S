# SNA 研究笔记：N=2..5 时还能用什么

> 目的：把社会网络分析（SNA）里**真正能落到"一个人 + 一个她 + 两三个第三方"这种规模上**的方法挑出来，给出公式、出处和实现参考。
> 结论先行：**SNA 的大部分工具是为 N≫1 设计的，在 dyad 上是退化的。真正还咬得动的只有"时域"和"三元"两类。**

---

## 1. 先划一条界：社交图 ≠ 记忆图

v2.0 草稿把"图拉普拉斯能量扩散"当作情绪的来源——它跑在**记忆图**（上万节点）上，却用来解释**人的状态**。这是两件事：

| | 社交图 | 记忆图 |
|---|---|---|
| 节点 | 她 / 你 / 2-3 个第三方 | 事实、情节、声学、文章（10³–10⁵） |
| 边 | 有符号的态度、互动强度 | 共现、语义、因果 |
| 规模 | **3–5** | 10³–10⁵ |
| 算法 | 时域模型、三元平衡、层级预算 | 扩散、聚类、检索排序 |
| 更新 | 每轮对话 | 定批量（`dream`） |

**SNA 属于左边。** 混在一起是 v2.0 最隐蔽的一个错误：在一个 10⁵ 节点图上算出来的"能量峰"，跟"她对你什么态度"没有任何因果关系。

## 2. N=2..5 时，哪些 SNA 量还成立

| 量 | 在 N=5 上 | 判定 |
|---|---|---|
| degree / strength | 只有 4 个值 | 退化为"就是那几个人"，无信息 |
| betweenness / closeness | dyad 上恒为 0 或 1 | ❌ 无意义 |
| PageRank / eigenvector | 5×5 矩阵，几乎是常数 | ❌ 无意义 |
| community detection（Louvain/Leiden） | 一个社区 | ❌ 无意义 |
| Burt constraint / effective size | 可算，但邻域结构不存在 | ❌ 现阶段无意义（`others` 长到 20+ 再说） |
| **有符号三元平衡** | 恰好需要 3 个节点 | ✅ **正好** |
| **互惠（时域）** | 两条事件序列 | ✅ |
| **关系强度（四要素）** | 全是时间序列 | ✅ |
| **邓巴层级分配** | 给 `others` 定数量与频率 | ✅ |
| **语体同步 LSM** | 两段文本 | ✅ |
| **时滞 / chronemics** | 一两列时间戳 | ✅ |

一句话：**结构类指标全废，时域和田德类（dyadic）指标全活。**

## 3. 四组机制

### 3.1 关系强度：Granovetter 的四要素是可算的

Granovetter (1973) 给的 tie strength 定义是四个可观察量：**互动时间量、情感强度、亲密度（相互吐露）、互惠性**。这四样我们全都有：

```
tie(a,b) = w1·frequency(a,b)      # 近 30 天互动次数 / 天
         + w2·recency(a,b)        # 上次互动距今，按 §3.5 的衰减率
         + w3·reciprocity(a,b)    # 见 3.2
         + w4·self_disclosure(a,b) # 对方说过的最深一层（社会渗透理论）
```

**关键补充（Kossinets & Watts）**：关系存续概率随时间衰减，而**衰减率本身与既往互动频率正相关**。翻译成设计语言是一条不对称规则：

> **越熟的人经得起越久的沉默，但一旦断了就更难恢复。**

这条和我们 §5.1.2 的 FSRS 衰减在形式上是一致的（S 越大衰减越慢），但语义不同：FSRS 的 S 是"记忆稳定性"，这里的 S 是"关系稳定性"。**两者应该共用同一个衰减曲线，但持有不同的 S。**

### 3.2 互惠：静态指数在 dyad 上退化，改用时域互惠

草稿里的 `ρ(t) = 双向交互比值` 有两个问题：

1. 比值形式对量纲不敏感：她发 10 条你回 1 条，和 1 条回 0.1 条，比值一样，但社交含义完全不同。
2. 密度依赖：Squartini et al. (2013, *Sci Rep* 3:2729) 证明二值互惠 `r = L↔/L` 的期望值就等于网络密度，必须用零模型归一化。**而在 dyad 上你根本没有零模型可估。**

正确的加权定义（Squartini et al. 2013）：

```
W↔ = Σ_{i≠j} min(w_ij, w_ji)          # 互惠部分，取 min 而不是比值
ρ_W = (W↔ − ⟨W↔⟩_null) / (W − ⟨W⟩_null)
```

**但在 N=2 上，唯一可估且不退化的是时域互惠**——即两个事件序列的相互激发强度：

```
λ_A(t) = μ_A + α_AA · Σ_{t_i<t} e^{-β(t-t_i)}        # 自己激发自己（阵发/习惯）
                + α_AB · Σ_{s_j<t} e^{-β(t-s_j)}      # B 激发 A（互惠）
```

`α_AB / α_AA` 就是**可估的互惠系数**：她对你的响应度，相对于她自己的惯性。它天然带量纲（速率），不需要零模型，且能只用几十个事件估出来（2×2 指数核，闭式 log-likelihood + 递归滤波，约 60 行，不需要 `tick` 那种 C++ 库）。

**这正好解释了草稿那句"霍克斯 × SNA 互惠度"为什么直觉是对的**——只是它没写出来：Hawkes 的互激矩阵 α 才是 dyad 上唯一能估的互惠量。静态比值只是它的一个粗代理。

参考实现：`tick`（Bacry et al.，C++/SWIG，工业级但重）；2×2 情形自己写更划算。事件数据反推网络的思路见 Linderman & Adams (2014) *Discovering Latent Network Structure in Point Process Data*。

### 3.3 有符号三元平衡：吃醋和辩护的数学形式

Heider (1946) 的结构平衡：三元组 (i,j,k) 中，`s_ij · s_jk · s_ki = +1` 为平衡，−1 为紧张。Carwright & Harary (1956) 推广到有符号图；Antal, Krapivsky & Redner (2005) 给出 triad 翻转动力学（约 log N 步收敛）。

**N=3 恰好是平衡理论唯一非平凡的最小结构**，所以这是 SNA 里唯一"人越少越合适"的工具。

它直接生成三种在任何陪伴系统里都极难得的行为：

| 情形 | 张力 | 她可能的行为 |
|---|---|---|
| 她喜欢你(+)，你喜欢 NPC(−)，她喜欢 NPC(+) | 不平衡 | **为难**：要么疏远 NPC，要么替你辩护，要么开始觉得你不讲道理 |
| 她喜欢你(+)，你和 NPC 关系好(+) | 平衡 | 不紧张，但会有"位置感"焦虑（第三方威胁，不是平衡问题） |
| 她讨厌 NPC(−)，你也讨厌 NPC(−) | 平衡（同仇敌忾） | **结盟**，这是最强的亲密加速器 |

实现只有两件事：一张 `attitudes(src, dst, valence)` 表，和每次 `dream` 里对"张力>阈值"的三元组做一次结算。**成本一天几毛钱，产出的是任何 prompt 工程都做不出来的东西。**

### 3.4 邓巴层级：给 `others` 定数量与频率，而不是拍脑袋

Dunbar 的层级（5 / 15 / 50 / 150，比例约 3；Zhou et al. 2005, Hamilton et al. 2007）经验事实有两条我们直接能用：

1. **每层有不同的接触频率**——不是"每层人更多"，而是"每层人联系更稀"。
2. 层级结构在线上社交网络里同样成立（Dunbar et al. 2015, *The structure of online social networks mirrors those in the offline world*），邮件网络亦然（Enron / Jmail 的分层 ego network 研究）。

落到设计上：

| 层 | 成员 | 接触频率 | 在我们系统里 |
|---|---|---|---|
| 5 | 你 | 每天多次 | 主对话 |
| 15 | 2–3 个 NPC | 每周 1–3 次 | `dream` 里的异步对话 |
| 50 | 弱关系/信息源 | 每月 | 爬虫抓到的文章、作者名 |

**这比"设计 3 个 NPC"有原则得多**：数量、频率、亲密度全部由层级比例决定，而且给出一个可检验的预测——**如果她一天主动找你 8 次，她就已经不在第 5 层了**。

### 3.5 语体同步（LSM）：一个免费的、被反复验证的亲密指标

Niederhoffer & Pennebaker (2002) 提出，Gonzales/Hancock/Pennebaker (2010) 验证它能预测群体凝聚力，Ireland & Pennebaker (2010) 用 `rLSM` 预测关系存续。

公式简单得可疑——只统计**功能词**（9 类：冠词、介词、代词、助动词、连词、否定词、量词、副词、非人称代词），每类算一个匹配度，再平均：

```
LSM_cat = 1 − |u1 − u2| / (u1 + u2 + ε)
LSM = mean(LSM_cat)          # ε 防止除零
```

关键性质：**它不看内容，只看语域**。所以

- 它测不到"她说了什么"，只测"她像不像在跟你说话"；
- 它**不可能被 prompt 直接虚增**（内容可以装，功能词分布很难长期装）；
- 它是 §7 评测里最好的漂移指标，因为它是**双侧的**：只有她一头变，LSM 会掉。

中文实现不需要 LIWC：手工 ~100 个功能词 + `jieba` 词性标注就够（`jieba.posseg` 的 r/u/p/c/d/m 标签大致对应）。这比接一个商业词典便宜得多，而且可复现。

⚠️ 一个要避开的坑：LSM 在 LLM 场景里有反向证据——2026 年有工作发现"评审压力会让模型**背离**评审者的语域，而不是趋同"（LLM-as-judge 场景）。所以 LSM 在我们这里只能当**测量**，不能当**优化目标**。一旦你去优化它，她就会变成学舌。

### 3.6 时滞（chronemics）：回复延迟是一等社会信号

Burgoon 的期望违背理论（EVT）：互动中偏离期望的行为会触发唤醒，并被解读为关系信号——**解读的方向由关系本身决定**（喜欢的人晚回 = "他忙"；不喜欢的人晚回 = "他不在乎"）。

对我们最有用的三条：

1. **延迟的绝对长度不重要，相对基线的偏离才重要**。所以要维护每个人的**个人回复时延基线**（中位数 + MAD），而不是全局平均值。
2. **她自己的延迟也必须是一个变量**，不能永远是"最佳延迟"。恒定秒回是最强的工具感来源。
3. **沉默是有语义的**：一次 >4h 的沉默，和三次 2h 的沉默，社会含义不同（前者是"事件"，后者是"模式"）。

### 3.7 意见动力学：给"有立场"一个数学形式

DeGroot (1974)：`x(t+1) = W x(t)`，W 行归一化的影响矩阵。
Friedkin-Johnsen (1990)：加一个"固执"项，`x(t+1) = Λ W x(t) + (I−Λ) x(0)`，Λ 是对他人的 susceptance。
Hegselmann-Krause (2002) 有界信任：**只被观点距离小于 ε 的邻居影响**。

第三条是关键。它给出了"不讨好"的**结构性**解释，而不是一句 prompt：

> 一个人不会被和他差距太大的观点说服。而 LLM 默认是 Friedkin-Johnsen 里 Λ 趋近 1 的极端——谁说话它都被拉动。

落到我们这里：她关于"某个话题"的立场存在 `attitudes` 里，受 `others` 影响时走**有界信任**更新（距离 > ε 就不动，甚至反向强化）。这和 §5.5 自我叙事是同一个方向的两层：叙事是"我是谁"，有界信任是"我不被谁改变"。

## 4. 实现参考清单

| 需要 | 用什么 | 备注 |
|---|---|---|
| 三元平衡结算 | 自己写（20 行）+ `networkx.triadic_census` 做校验 | `triadic_census` 只接受有符号图时需转换 |
| 2×2 互激 Hawkes | 自己写（闭式 log-lik + 递归滤波，~60 行） | 不要装 `tick`（C++ 构建，1.6G 机器不划算） |
| LSM | `jieba.posseg` + 自建 100 词功能词表 | 不要引入 LIWC（商业） |
| 有界信任 | 纯 numpy，3×3 矩阵 | — |
| 层级预算 | 配置表，不需要库 | 5/15/50 的比例写进 `config.toml` |
| 图算法（记忆图，后期） | `python-igraph` + `leidenalg` | 只在 V>1000 时才需要，现阶段用 `networkx` |
| 结构洞（如果 `others` 长大） | `networkx.structuralholes.constraint` | 现在**不要**用，N=5 上是噪声 |

全部依赖都在 `numpy`/`scipy`/`networkx`/`jieba` 之内。**没有一个是重型库，1.6 GiB 的机器扛得住。**

## 5. 明确的拒绝清单（省得以后反复讨论）

1. **不要在 dyad 上用任何需要零模型的统计量。** 你估不出期望值，得到的数只是噪声的形状。
2. **不要在社交图上做社区发现或中心性。** N=5 时它们全是常数。
3. **不要把 LSM 当优化目标。** 只当测量。
4. **不要用全局平均值做时滞基线。** 每个人的基线不同，偏离才有意义。
5. **不要把 SNA 的显著性检验搬进来。** 单用户、单 dyad，没有统计功效这回事；这些模型在这里是**机制**，不是**检验**。
